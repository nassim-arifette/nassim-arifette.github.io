## The game

RAGOTS is a browser island game built by our team at the Paris AI Gaming Hackathon. Each character has a personality, memory, and relationships that evolve through free-form conversations.

When the player leaves, islanders keep talking: rumors spread and change, and the player returns to a gossip gazette describing what happened.

## Technical work

The game uses TypeScript, Vite, and Three.js for an HD-2D world, with Gemini-powered dialogue and social simulation. Gradium supplies character voices and speech input; game code validates model outputs and provides an offline fallback.

We used Cognition's Devin as an AI teammate to implement features on separate branches and test them through pull requests.
